# Privacy

All repository scripts run locally. This project includes no telemetry, analytics, tracking, or automatic data upload.

Audit and sanitizer output remains on the local machine unless the operator redirects, copies, or shares it. Public mode applies common redaction rules, but the operator must still review output because locally defined identifiers and secret formats can differ.

The public repository does not contain production environment files, private VPN material, real private network addresses, external hostnames, or service credentials.
